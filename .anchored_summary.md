## Key Decisions
- Replaced JWT auth with Clerk for managed authentication, session handling, and built-in UI components
- `/api/login` route removed entirely — Clerk handles sign-in; server verifies session tokens via `@clerk/backend`
- Admin email restriction done in `ProtectedRoute` (frontend) — simplest approach for single-admin store
- Token sync via `TokenSync` component (periodic `getToken()` call) rather than per-request `getToken()` in `api.js`
- Two separate polish passes applied: first from Emil Kowalski's design engineering philosophy (easing, skeletons, active states), second from impeccable framework (lucide icons, border removal, stat card icons). Third pass retrofitted remaining 3 admin pages to match.
- Skeleton components in `src/components/Skeleton.jsx` as reusable loading primitives
- `fieldClass` extracted per-file to reduce duplication across CRUD pages
